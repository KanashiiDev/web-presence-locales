# <img align="center" src="https://raw.githubusercontent.com/KanashiiDev/discord-music-rpc/refs/heads/main/app/assets/icon/icon.png" alt="Extension Icon" width="48" height="48"> Web Presence - Locales

Community-maintained translations for [Web Presence](https://github.com/KanashiiDev/web-presence), the open-source browser extension and desktop bridge that shows what you're listening to or watching in Discord Rich Presence.

This repository holds the translation files (`locales/<lang>/<namespace>.json`), the submission queue, and the automation that validates and applies community contributions. The authoritative English source lives in the [main repository](https://github.com/KanashiiDev/web-presence/tree/main/locales/en).

Translations are contributed exclusively through the translation editor built into the Web Presence extension. This repository is not meant to be edited or run locally. See **[CONTRIBUTING.md](CONTRIBUTING.md)** to get started.
