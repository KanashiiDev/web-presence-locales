This repository contains community-maintained translations for [Web Presence](https://github.com/KanashiiDev/web-presence).

## Contributing

Translations are contributed exclusively through the translation editor built into the Web Presence extension. This repository is not meant to be edited or run locally. See **[CONTRIBUTING.md](CONTRIBUTING.md)** to get started.
