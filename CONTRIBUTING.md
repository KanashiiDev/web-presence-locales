Thanks for helping translate [Web Presence](https://github.com/KanashiiDev/web-presence)!

> [!IMPORTANT]
> Only translations created via the **Translation Editor** inside the Web Presence browser extension will be accepted. Manually written or hand-edited files are not accepted.

## How it works

- Select a language in the editor and translate the keys shown.
- Click **Submit translations** in the left sidebar to submit your translations.

## Questions

If you're unsure about something, open an issue in this repository before submitting a PR.
